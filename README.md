# Workshop Seat Allocation System

## 📌 Description
A Python-Tkinter based Workshop Seat Allocation System integrated with MySQL database.  
Features include student registration, seat assignment, and dashboard for managing workshop enrollments.

## ⚙️ Technologies Used
- Python (Tkinter for GUI)
- MySQL (Database)
- mysql-connector-python (Library)

## 🚀 Features
- User Login & Registration
- Student Seat Allocation
- Course Selection
- Dashboard with Seat Records
- Delete/Update Records

## 🛠 Installation
1. Install Python (>=3.8)
2. Install required library:
   ```bash
   pip install mysql-connector-python
